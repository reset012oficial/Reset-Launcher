# Reset-Launcher
Um Launcher de minecraft Horizon (minecraft reescrito em rust) 100% brasileiro e feito por um desenvolvedor solo

O Reset Launcher foi pensado em uma forma alternativa ao horizon launcher, apresentando mais funcionalidades (como o modo offline) e sendo leve e compativel para diversas versoes do windows (foi testado do windows 10 ao 7).

# Funções: 

O launcher apresenta um modo offline, ajudando players que queiram jogar sem o uso de internet (você precisa da copia original do server.jar do minecraft 26.3 para poder jogar e após o preparo pedido pelo launcher o jogador poderá jogar sem o uso de internet ou em servidores offline). tambem possui um sistema de nome de usuario para os players offline.

O launcher apresenta uma area dedicada a mods, resource-packs e shaders que contará com uma area expecifica para a instalação automatica desses recursos (por enquanto o jogador precisa instalar por fora e pelo launcher acessar a pasta e copiar os arquivos).

O launcher possui um sistema de skins personalizadas em que o jogador mesmo no modo offline poderá trocar sua skin, assim permitindo que ele não precise utilizar as skins padrão do jogo.

Ele tambem possui uma area de configuração que lá o usuario poderá selecionar a quantidade de memoria ram, o tamanho da janela, distancia de renderização, configurações de mundo e outras coisas.


# Requisitos do Sistema:

*JDK 25+ (launcher foi testado na versão *25.0.4.1* 2026-08-18 LTS mas funciona em versões superiores)

Source code do Horizon Launcher extraido (https://github.com/horizon-rust/horizon)

Server.jar do minecraft 26.3 (não restribuimos a copia original)


Instalação:

Para fazer a instalação do launcher está disponivel um instalador e o .zip portatil assim permitindo que o usuario possa usa-lo sem precisar da instalação (é claro que ele ainda vai precisar dos requisitos), siga os passos do instalador ou abra o reset launcher.exe dentro do .zip portatil.
