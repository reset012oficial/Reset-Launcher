# Reset-Launcher
Um launcher de Minecraft Java (Minecraft reescrito em Rust) 100% brasileiro e feito por um desenvolvedor solo.

O Reset Launcher foi pensado como uma forma alternativa ao Horizon Launcher, apresentando diferentes funcionalidades (como o modo offline) e sendo leve e compatível com diversas versões do Windows (foi testado do Windows 10 ao 7). O launcher utiliza parte do código do Horizon Launcher para rodar o Minecraft reescrito em Rust.

# Funções:

O launcher apresenta um modo offline, ajudando players que queiram jogar sem o uso de internet (após o preparo pedido pelo launcher, o jogador poderá jogar sem o uso de internet ou em servidores offline). Também possui um sistema de nome de usuário para os players offline.

O launcher apresenta uma área dedicada a mods, resource packs e shaders, que conta com uma área específica para a instalação desses recursos. Também há links que levam para a aba de mods do Horizon Launcher.

O launcher possui um sistema de skins personalizadas em que o jogador, mesmo no modo offline, poderá trocar sua skin, assim permitindo que ele não precise utilizar as skins padrão do jogo.

Ele também possui uma área de configuração na qual o usuário poderá selecionar a linguagem do launcher (possui inglês e português), quantidade de memória RAM, tamanho da janela, distância de renderização, configurações de mundo e outras coisas.

# Requisitos do Sistema:

* JDK 25+ (o launcher foi testado na versão *25.0.4.1* 2026-08-18 LTS, mas funciona em versões superiores).

Instalação:

Para fazer a instalação do launcher, está disponível um instalador e o .zip portátil, assim permitindo que o usuário possa usá-lo sem precisar da instalação (é claro que ele ainda vai precisar dos requisitos). Siga os passos do instalador ou abra o Reset Launcher.exe dentro do .zip portátil.
